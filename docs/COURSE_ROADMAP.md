# План курса: Python с нуля до MCP Web Search для LM Studio

## Статус программы

**Основной курс: 17 уроков.** Его цель — не только подключить MCP-сервер к LM Studio, но и научиться проверять его работу, диагностировать ошибки и поддерживать качество проекта.

**Дополнительные уроки: 18–19.** Они не входят в обязательную программу и изучаются по желанию после основного курса.

## Основной курс

## Урок 01. От Python до MCP: что мы будем создавать
- Что такое Python и зачем он нужен.
- MCP (Model Context Protocol — протокол взаимодействия модели с внешними инструментами).
- Как взаимодействуют LM Studio, языковая модель и MCP-сервер.
- Что такое Web Search и Web Fetch и чем они отличаются.
- Архитектура итоговой программы и план её создания.

**Результат:** ученик понимает цель и устройство проекта до написания кода.

## Урок 02. Установка Python и Visual Studio Code
- Установка Python и VS Code, расширение Python, проверка `python --version`.
- Создание папки проекта и открытие её в редакторе.
- Настройка интерпретатора Python и терминала PowerShell.
- Создание первого файла, запуск программы и типичные ошибки.

**Результат:** готовое рабочее место для запуска Python-программ.

## Урок 03. Переменные, типы данных, строки и комментарии
- Переменные и оператор присваивания `=`.
- Числа, строки, логические значения и `None`.
- `print()`, f-строки, комментарии и понятные сообщения об ошибках.
- Первые настройки: имя сервера, тайм-аут и лимит результатов.

**Результат:** программа хранит настройки и выводит информацию о работе.

## Урок 04. Условия, функции и возврат результата
- `if`, `elif`, `else`, сравнения, логические операторы и проверки данных.
- `def`, аргументы, параметры и `return`.
- Разделение программы на небольшие функции.

**Результат:** первые функции проверки поискового запроса и подготовки ответа.

## Урок 05. Списки, словари, циклы и JSON
- Списки результатов поиска.
- Словари для названия, URL и описания страницы.
- Цикл `for` и обработка элементов коллекций.
- JSON, проверка полей и обработка пустых результатов.

**Результат:** структурированная обработка результатов поиска.

## Урок 06. Модули, библиотеки и виртуальное окружение
- Модуль, пакет и зависимость.
- `import` и `from ... import ...`.
- Создание `.venv`, установка библиотек через `pip`.
- `requirements.txt` и воспроизводимая установка.

**Результат:** изолированная среда разработки MCP-сервера.

## Урок 07. Интернет-запросы и обработка ошибок
- URL, HTTP, запрос и ответ сервера.
- Выполнение HTTP-запросов из Python.
- Тайм-ауты, коды ответов, исключения, `try` и `except`.
- Почему сеть может дать сбой даже при правильном коде.

**Результат:** получение веб-страниц с корректной обработкой сетевых ошибок.

## Урок 08. Создаём Web Search
- Выбор поискового провайдера без обязательного API-ключа.
- Получение результатов, извлечение названия, ссылки и фрагмента текста.
- Ограничение количества результатов.
- Пустая выдача и ошибки провайдера.

**Результат:** функция `web_search`, проверенная независимо от MCP.

## Урок 09. Создаём Web Fetch
- Получение страницы по найденному URL.
- Разница между HTML и читаемым текстом.
- Извлечение основного содержимого и ограничение размера.
- Обработка недоступных страниц, редиректов и неподдерживаемого содержимого.

**Результат:** функция `web_fetch`, возвращающая модели текст страницы.

## Урок 10. Превращаем функции в MCP-сервер
- Как работает MCP и зачем нужен MCP SDK для Python.
- Сервер, инструмент и схема входных данных.
- Регистрация `web_search` и `web_fetch`.
- `stdio` — стандартные потоки ввода и вывода.
- Проверка вызовов инструментов и передача результатов модели.

**Результат:** оба инструмента доступны через единый протокол MCP.

## Урок 11. Безопасность, тестирование и исправление ошибок
- Проверка входных данных и допустимых URL.
- Защита от обращения к локальным адресам и опасных редиректов.
- Ограничение времени ожидания и объёма данных.
- Тестирование функций и типовых ошибок.
- Проверка цепочки `web_search → web_fetch` и диагностика повторных вызовов.

**Результат:** сервер проверен на успешных и ошибочных сценариях; известные ограничения защиты задокументированы.

## Урок 12. Подключаем MCP к LM Studio и запускаем без VS Code
- Подготовка структуры проекта.
- Настройка MCP в LM Studio.
- Проверка обнаружения и вызова обоих инструментов.
- Практический тест с Qwen: поиск, загрузка страницы и ответ по содержимому.
- Проверка после закрытия VS Code и терминала разработки.
- Разница между запуском через Python и дополнительной упаковкой в `.exe`.

**Результат:** настроенный MCP Web Search для LM Studio без необходимости держать VS Code открытым. Подключение считается проверенным только после фактического запуска и вызова инструментов.

## Урок 13. Конфигурация, переменные окружения и логирование
- Отделение настроек от прикладной логики.
- Переменные окружения и файл `.env`, если он нужен проекту.
- Настройка тайм-аутов, лимитов и параметров поиска.
- Уровни логирования и безопасная диагностика.
- Почему нельзя писать произвольные сообщения в `stdout` при использовании MCP-транспорта `stdio`.

**Результат:** настройки можно менять без редактирования логики, а ошибки можно диагностировать без нарушения MCP-протокола.

## Урок 14. Типизация Python и контракты функций
- Аннотации типов и их назначение.
- Типы аргументов и возвращаемых значений.
- Типизация списков, словарей и необязательных значений.
- Единый формат успешных результатов и ошибок.
- Как контракты функций упрощают поддержку и уменьшают неоднозначность.

**Результат:** интерфейсы функций и структура ответов понятны и последовательны.

## Урок 15. Углублённое тестирование MCP-сервера
- Разница между модульными, интеграционными и ручными сетевыми тестами.
- Подмена HTTP-ответов и тестирование без реального интернета.
- Проверка регистрации инструментов, входных схем и возвращаемых результатов.
- Тестирование ошибок протокола и цепочки `web_search → web_fetch`.
- Регрессионные тесты и критерии готовности перед изменением версии.

**Результат:** проверяется не только работа отдельных функций, но и взаимодействие компонентов MCP.

## Урок 16. Как модель использует Web Search и Web Fetch
- Как модель выбирает инструмент и формирует аргументы.
- Почему модель может не вызвать инструмент, выбрать неверную страницу или повторить вызов.
- Описания инструментов и ограничения входных параметров.
- Ограничение объёма выдачи и расход контекстного окна.
- Недоверенное содержимое веб-страниц и защита от инструкций, встроенных в найденный текст.
- Как различать ошибку модели, MCP-клиента, сервера и внешнего сайта.

**Результат:** ученик умеет диагностировать поведение модели, не приписывая автоматически любую проблему серверному коду.

## Урок 17. Надёжность поиска и извлечения текста
- Изменения HTML-разметки поисковика и сайтов.
- CAPTCHA, блокировки, ограничения частоты и временная недоступность.
- Кодировки, типы содержимого и пустые страницы.
- Обработка страниц, которые не являются HTML, включая обнаружение PDF и понятный отказ, если извлечение PDF не реализовано.
- Устойчивые ошибки, повторные попытки там, где они оправданы, и защита от бесконечных повторов.
- Диагностика качества результатов и план регрессионной проверки.

**Результат:** ученик умеет находить причины сбоев при работе с реальными сайтами и улучшать устойчивость веб-инструментов.

## Дополнительные уроки

Эти темы не входят в обязательные 17 уроков. Они расширяют проект после освоения основной программы.

## Урок 18. Асинхронность и параллельные запросы
- Понятия `async`, `await`, корутин и конкурентного выполнения.
- Когда параллельная загрузка нескольких страниц ускоряет работу.
- Ограничение одновременных запросов и обработка ошибок.
- Сравнение простого последовательного решения с асинхронным.
- Почему не стоит усложнять рабочий код асинхронностью без измеримой необходимости.

**Результат:** ученик понимает, когда и как можно ускорить веб-инструменты.

## Урок 19. Упаковка в EXE и переносимая установка
- Варианты упаковки Python-приложения в исполняемый файл.
- Включение зависимостей и конфигурационных файлов.
- Абсолютные и относительные пути, хранение настроек.
- Проверка на другом компьютере и диагностика отсутствующих компонентов.
- Ограничения EXE-упаковки для MCP-сервера и совместимость с LM Studio.

**Результат:** подготовлен дополнительный вариант распространения сервера; самостоятельная работа EXE подтверждается отдельным тестированием.

## Стандарт подготовки урока

Каждый урок содержит подробный лекционный текст для видео, определения иностранных терминов, построчный разбор кода, отдельное объяснение новых операторов и конструкций с указанием причин выбора и преимуществ, команды PowerShell, ожидаемые результаты, диагностику типичных ошибок, практическое задание, контрольные вопросы и критерии готовности.

Полный текст урока публикуется в чате и сохраняется в соответствующем каталоге репозитория. Ссылки на файлы не заменяют лекционный материал в чате.

## Принципы курса

1. Сначала изучаем Python на небольших примерах, затем применяем его в проекте.
2. Сначала проверяем `web_search` и `web_fetch` независимо, затем объединяем их в MCP-сервер.
3. Отличаем автоматические тесты с подменённой сетью от реальных проверок внешних сервисов.
4. Не объявляем интеграцию проверенной без фактического запуска и вызова инструментов.
5. Сохраняем рабочую простоту: новые архитектурные решения вводим, когда понятна их задача и польза.
6. Уроки 18–19 остаются дополнительными и не меняют нумерацию основного курса.
