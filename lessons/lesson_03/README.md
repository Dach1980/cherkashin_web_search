## 1. Что мы строим и почему начинаем с переменных

Наш итоговый проект — Python-сервер для протокола MCP, который позволит LM Studio вызывать две функции: `web_search` для поиска страниц и `web_fetch` для загрузки и чтения конкретной страницы.

Для такой программы нужно хранить разные виды информации:
- название сервера;
- время ожидания ответа от сайта;
- максимальное количество результатов поиска;
- максимально допустимый объём текста страницы;
- адрес страницы, заголовок, найденный текст;
- сообщения об ошибках.

Пока это только значения, но позднее они будут участвовать в логике программы. Например, прежде чем загружать страницу, мы проверим её адрес, а затем ограничим время ожидания и объём текста. Чтобы не вписывать одни и те же числа и строки в разные места программы, будем сохранять их в переменных.

**Переменная** — это имя, через которое программа обращается к некоторому значению. В Python переменная появляется, когда мы присваиваем ей значение.

Пример:

```python
server_name = "web-search-mcp"
print(server_name)
```

Первая строка сохраняет строковое значение в переменной `server_name`. Вторая передаёт это значение функции `print()`, которая выводит его в терминал.

Ожидаемый результат:

```text
web-search-mcp
```

## 2. Оператор присваивания `=`

В выражении `server_name = "web-search-mcp"` символ `=` — **оператор присваивания**. Он связывает имя переменной со значением справа.

Важно: в Python `=` не означает «проверь, равны ли левая и правая части». Для проверки равенства позже будем использовать `==`. Это разные операторы.

Разберём присваивание по шагам:

1. Python вычисляет выражение справа от `=`.
2. Получает значение `"web-search-mcp"`.
3. Связывает это значение с именем `server_name`.
4. При последующем обращении к `server_name` программа получает сохранённое значение.

Присваивание можно использовать повторно:

```python
server_name = "web-search-mcp"
print(server_name)

server_name = "my-first-server"
print(server_name)
```

Результат:

```text
web-search-mcp
my-first-server
```

Вторая строка присваивания связывает имя с новым значением. Поэтому при следующем выводе мы видим уже новое название.

### Почему переменные полезны

- **Понятность:** имя `DEFAULT_TIMEOUT_SECONDS` понятнее, чем необъяснённое число `15`.
- **Повторное использование:** значение можно использовать в нескольких местах.
- **Удобное изменение:** если нужно поменять лимит, часто достаточно исправить одно присваивание.
- **Меньше ошибок:** одна настройка в одном месте снижает риск, что в разных функциях случайно окажутся разные значения.

## 3. Как правильно называть переменные

Имя переменной должно помогать понять, что хранится внутри. В Python обычно используют стиль `snake_case` («змеиный регистр»): слова пишут строчными буквами и разделяют символом подчёркивания.

Примеры хороших имён:

```python
server_name = "web-search-mcp"
timeout_seconds = 15
max_search_results = 5
page_text = "Текст страницы"
```

Правила имён:
- можно использовать латинские буквы, цифры и подчёркивание;
- имя не должно начинаться с цифры;
- пробелы в имени недопустимы;
- регистр имеет значение: `page_text` и `Page_Text` — разные имена;
- нельзя использовать зарезервированные слова Python, например `if`, `for`, `class` в роли обычных имён переменных.

Технически Python допускает кириллические имена, но в учебном и рабочем коде проекта мы будем использовать английские имена. Это облегчает чтение кода, поиск примеров и совместную работу с библиотеками.

Плохие или неудобные варианты:

```python
x = 15
a = "web-search-mcp"
max results = 5
```

В первых двух строках имена слишком неинформативны. Третья строка вызовет синтаксическую ошибку из-за пробела в имени. Правильно:

```python
timeout_seconds = 15
server_name = "web-search-mcp"
max_results = 5
```

## 4. Типы данных: какие значения бывают

**Тип данных** — это категория значения, которая определяет, какую информацию оно представляет и какие операции с ним обычно имеют смысл.

В Python на этом этапе нам важны пять типов.

### 4.1. Целые числа — `int`

`int` — сокращение от английского *integer*, «целое число». Примеры: `0`, `5`, `15`, `-3`.

```python
max_search_results = 5
print(max_search_results)
```

Число `5` записано без кавычек, поэтому Python воспринимает его как число, а не текст. Целые числа подходят для счётчиков, количества результатов и целых единиц.

### 4.2. Числа с дробной частью — `float`

`float` — тип чисел с плавающей точкой (*floating-point number*). Примеры: `1.5`, `0.25`, `15.0`.

```python
temperature = 21.5
print(temperature)
```

В Python десятичная часть записывается через точку, а не через запятую. Значение `21,5` не является привычной записью одного дробного числа в Python: запятая используется как разделитель элементов в некоторых конструкциях.

Для настройки тайм-аутов можно использовать целое число секунд, например `15`, или дробное, если библиотека допускает более точную настройку, например `2.5`.

Не следует полагаться на абсолютно точное представление любой десятичной дроби в `float`: некоторые дроби хранятся приближённо. Для простых тайм-аутов и измерений это обычно подходит.

### 4.3. Строки — `str`

`str` — сокращение от *string*, «строка», то есть текстовая последовательность символов.

```python
server_name = "web-search-mcp"
page_title = "Как работает MCP"
print(server_name)
print(page_title)
```

Строку обычно заключают в одинарные или двойные кавычки:

```python
language = "Python"
message = 'Программа запущена'
```

В этих примерах одинарные и двойные кавычки выполняют одну задачу. Выбирайте вариант, который помогает сделать текст удобочитаемым. Например:

```python
message = "Сервер готов к работе"
quote = "В документации написано: 'Запустите программу'"
```

Внешние двойные кавычки позволяют без дополнительных действий использовать одинарные внутри строки.

Кавычки являются частью записи кода, но обычно не входят в само текстовое значение. Например, значение переменной `language` — это слово `Python`, а не слово вместе с символами кавычек.

### 4.4. Логические значения — `bool`

`bool` — сокращение от *Boolean*, «логический тип». У него два значения: `True` и `False`, то есть «истина» и «ложь».

```python
debug_mode = True
web_fetch_enabled = False

print(debug_mode)
print(web_fetch_enabled)
```

Обратите внимание: `True` и `False` пишутся с заглавной первой буквой и без кавычек. Запись `"True"` — это строка, а `True` — логическое значение. Внешне они похожи, но тип у них разный.

Позже логические значения будут управлять поведением программы: например, разрешён ли дополнительный режим или успешно ли прошла проверка.

### 4.5. Отсутствие значения — `None`

`None` — специальное значение Python, означающее отсутствие значения или то, что значение пока не задано.

```python
last_error = None
print(last_error)
```

Результат:

```text
None
```

Это не строка `"None"`. Кавычек нет, потому что `None` — специальное значение языка.

В дальнейшем `None` может означать, например, что заголовок страницы ещё не получен или дополнительная настройка не задана. Это не то же самое, что пустая строка `""`, ноль `0` или `False`: каждое из этих значений имеет собственный смысл.

## 5. Кавычки, числа и частая ошибка начинающих

Сравним две строки:

```python
timeout_seconds = 15
timeout_text = "15"

print(timeout_seconds)
print(timeout_text)
```

На экране обе строки вывода выглядят как `15`, но первая переменная содержит целое число, а вторая — текст. Тип данных важен, когда мы начнём выполнять вычисления.

Например:

```python
print(15 + 5)
print("15" + "5")
```

Результат:

```text
20
155
```

В первой строке `+` складывает два числа. Во второй `+` соединяет две строки: получается текст `155`, а не число двадцать.

Не заключайте числа в кавычки, если планируете использовать их как числа. И не убирайте кавычки вокруг текста: запись `web-search-mcp` без кавычек будет интерпретироваться как выражение с именами и операторами, а не как текстовое название.

## 6. Функция `print()`: выводим значения

**Функция** — именованный блок кода, который можно вызвать для выполнения определённого действия. Функцию `print()` мы уже использовали в уроке 2. Сейчас будем применять её к разным типам данных.

```python
print("Сервер:", "web-search-mcp")
print("Лимит результатов:", 5)
print("Режим отладки:", True)
print("Последняя ошибка:", None)
```

Функция `print()` выводит переданные ей значения. Несколько значений можно разделять запятыми. По умолчанию `print()` вставляет между ними пробел, поэтому вывод получается удобным для чтения.

Результат:

```text
Сервер: web-search-mcp
Лимит результатов: 5
Режим отладки: True
Последняя ошибка: None
```

Запятая между аргументами вызова `print()` — не то же самое, что плюс между строками. С запятой функция получает отдельные значения и выводит их с разделителем. С `+` строки соединяются заранее, а числа складываются, если оба операнда числовые.

## 7. Узнаём тип значения с помощью `type()`

Новая функция этого урока — `type()`. Её название по-английски означает «тип». Она возвращает информацию о типе переданного значения.

```python
print(type(15))
print(type(21.5))
print(type("Python"))
print(type(True))
print(type(None))
```

Результат будет примерно таким:

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
```

Слово `class` здесь связано с внутренним представлением типов в Python. Пока достаточно научиться читать названия: `int`, `float`, `str`, `bool`, `NoneType`.

Почему это полезно? Если функция неожиданно получила текст вместо числа, проверка типа помогает обнаружить ошибку. Например, лимит результатов `"5"` и лимит результатов `5` — не одно и то же.

В обычной программе не нужно постоянно выводить типы. Это учебный инструмент для понимания и диагностики.

## 8. Что такое f-строки и зачем они нужны

**f-строка** (*formatted string literal*, форматированная строковая литера) — удобный способ вставлять значения переменных прямо внутрь текста. Перед открывающей кавычкой ставится буква `f`, а выражения, значения которых нужно подставить, помещаются в фигурные скобки `{}`.

Пример:

```python
server_name = "web-search-mcp"
timeout_seconds = 15

print(f"Имя сервера: {server_name}")
print(f"Тайм-аут: {timeout_seconds} секунд")
```

Результат:

```text
Имя сервера: web-search-mcp
Тайм-аут: 15 секунд
```

Разберём новые элементы:
- буква `f` перед строкой сообщает Python, что внутри есть выражения для подстановки;
- фигурные скобки `{server_name}` обозначают место, куда нужно подставить значение переменной;
- обычный текст вокруг фигурных скобок остаётся текстом;
- имя переменной внутри скобок пишется без кавычек.

### Почему f-строки удобнее

Можно было бы собрать сообщение иначе:

```python
server_name = "web-search-mcp"
print("Имя сервера: " + server_name)
```

Но когда в сообщении смешаны числа, строки и другие значения, конкатенация (от английского *concatenation* — соединение строк) становится неудобной. Например, попытка выполнить `"Тайм-аут: " + 15` вызовет ошибку: Python не соединяет строку с целым числом через `+` автоматически.

С f-строкой всё проще:

```python
timeout_seconds = 15
print(f"Тайм-аут: {timeout_seconds} секунд")
```

Python сам преобразует подставляемое значение в текстовое представление для вывода. F-строки делают сообщения читаемее и уменьшают количество лишних преобразований.

Внутри фигурных скобок можно разместить и выражение:

```python
first_limit = 3
second_limit = 2
print(f"Общий лимит в примере: {first_limit + second_limit}")
```

Результат:

```text
Общий лимит в примере: 5
```

Python вычисляет выражение `first_limit + second_limit`, затем подставляет результат в строку. Не перегружайте f-строку сложной логикой: обычно удобнее сначала вычислить значение, присвоить его понятной переменной, а потом вывести.

## 9. Комментарии: объясняем код человеку

**Комментарий** — текст для разработчика, который Python не исполняет как команду. В Python однострочный комментарий начинается с символа `#`.

```python
# Имя будущего MCP-сервера
server_name = "web-search-mcp"

# Максимальное число результатов одного поиска
max_search_results = 5
```

Строки, начинающиеся с `#`, помогают понять назначение настроек. Само значение комментария не влияет на выполнение программы.

Комментарий также можно поставить после кода:

```python
timeout_seconds = 15  # Максимальное ожидание ответа, в секундах
```

Используйте комментарии, чтобы объяснять **почему** решение принято или что означает настройка, а не пересказывать каждую очевидную строку. Например, комментарий «присваиваем 15 переменной» мало полезен; «ограничиваем ожидание ответа, чтобы запрос не зависал бесконечно» объясняет смысл.

В этом уроке мы используем только однострочные комментарии. Для большого текстового описания обычно лучше подходит документация или отдельный текстовый файл.

## 10. Константы: значения настроек, которые не планируем менять

В Python есть соглашение об именовании констант: имена пишут заглавными буквами, слова разделяют подчёркиванием. Например:

```python
SERVER_NAME = "web-search-mcp"
DEFAULT_TIMEOUT_SECONDS = 15
DEFAULT_MAX_SEARCH_RESULTS = 5
DEFAULT_MAX_PAGE_CHARS = 12_000
```

**Константа** — значение, которое по смыслу программы считается постоянной настройкой. В отличие от некоторых языков, обычное присваивание в Python не запрещает изменить такую переменную. Заглавное имя — это соглашение для разработчиков: «не меняй это значение без необходимости».

Запись `12_000` — это целое число двенадцать тысяч. Подчёркивание внутри числового литерала (*literal* — значение, записанное непосредственно в коде) помогает читать большие числа и не меняет значение. Например, `12_000` и `12000` — одно и то же число.

Для нашего проекта эти настройки означают:
- `SERVER_NAME` — внутреннее имя MCP-сервера;
- `DEFAULT_TIMEOUT_SECONDS` — время ожидания сетевого ответа по умолчанию;
- `DEFAULT_MAX_SEARCH_RESULTS` — максимальное количество результатов поиска по умолчанию;
- `DEFAULT_MAX_PAGE_CHARS` — ограничение числа символов текста страницы, которое мы будем пытаться вернуть.

Последнее ограничение — это именно число символов текста, а не точное количество токенов языковой модели и не гарантированный размер ответа в байтах. Позже при загрузке страниц добавим отдельные ограничения для сетевого ответа и объёма данных.

## 11. Практическая работа: создаём настройки проекта

Откройте папку репозитория `cherkashin_web_search` в Visual Studio Code. Внутри папки `src/web_search_mcp` уже предусмотрен файл `config.py`. Если вы выполняете урок в отдельной учебной папке, можно сначала создать файл `lesson_03.py` и повторить пример там.

Вставьте в `config.py` следующий код:

```python
"""Начальные настройки проекта.

Пока здесь нет сетевых запросов и запуска MCP-сервера.
Этот модуль только хранит значения, которые будут использоваться дальше.
"""

SERVER_NAME = "web-search-mcp"
DEFAULT_TIMEOUT_SECONDS = 15
DEFAULT_MAX_SEARCH_RESULTS = 5
DEFAULT_MAX_PAGE_CHARS = 12_000

print(f"Имя сервера: {SERVER_NAME}")
print(f"Тайм-аут: {DEFAULT_TIMEOUT_SECONDS} секунд")
print(f"Максимум результатов поиска: {DEFAULT_MAX_SEARCH_RESULTS}")
print(f"Лимит текста страницы: {DEFAULT_MAX_PAGE_CHARS} символов")
```

В этом примере есть ещё один вид строк в тройных кавычках. В начале модуля это **строка документации модуля** (*module docstring*): короткое описание назначения файла. Python и инструменты разработчика могут использовать её как документацию. В отличие от комментария с `#`, это строковое значение, размещённое в специальном месте в начале модуля. Пока используем её как описание файла.

Важное замечание: в текущем проекте `config.py` задуман как модуль настроек, а не как программа, которая печатает сообщения при импорте. Поэтому для чистой архитектуры лучше оставить в `config.py` только документацию и четыре настройки, а вывод поместить в отдельный файл `lesson_03.py`. Именно так и рекомендуется сделать в основном репозитории:

**Файл `src/web_search_mcp/config.py`:**

```python
"""Начальные настройки проекта. Сетевой логики здесь пока нет."""

SERVER_NAME = "web-search-mcp"
DEFAULT_TIMEOUT_SECONDS = 15
DEFAULT_MAX_SEARCH_RESULTS = 5
DEFAULT_MAX_PAGE_CHARS = 12_000
```

**Файл `lesson_03.py` в корне репозитория:**

```python
from src.web_search_mcp.config import (
    SERVER_NAME,
    DEFAULT_TIMEOUT_SECONDS,
    DEFAULT_MAX_SEARCH_RESULTS,
    DEFAULT_MAX_PAGE_CHARS,
)

print(f"Имя сервера: {SERVER_NAME}")
print(f"Тайм-аут: {DEFAULT_TIMEOUT_SECONDS} секунд")
print(f"Максимум результатов поиска: {DEFAULT_MAX_SEARCH_RESULTS}")
print(f"Лимит текста страницы: {DEFAULT_MAX_PAGE_CHARS} символов")
```

Здесь впервые встречается конструкция `from ... import ...`. Она импортирует выбранные имена из модуля. **Модуль** — Python-файл, который можно использовать из другого кода. В нашем случае `config.py` хранит настройки, а `lesson_03.py` показывает их. Такое разделение помогает не смешивать настройки с выводом и сетевой логикой.

Многострочная запись импорта оформлена скобками. Это позволяет перечислить несколько имён на отдельных строках, не используя символ продолжения строки `\`. Скобки делают длинный список удобнее для чтения и последующего редактирования.

Если у вас пока нет пакета `src` или запуск импорта из корня не работает, не переименовывайте папки наугад. Для первого знакомства запустите самостоятельный файл `lesson_03.py` с теми же значениями, объявленными непосредственно в нём. Позже мы отдельно разберём импорты и структуру пакета.

## 13. Типичные ошибки

### Ошибка 1. Пропущены кавычки у текста

Неправильно:

```python
server_name = web-search-mcp
```

Python пытается трактовать запись как код, а не как текст. Правильно:

```python
server_name = "web-search-mcp"
```

### Ошибка 2. Число ошибочно превращено в строку

```python
max_search_results = "5"
```

Это допустимый код, но тип значения — строка. Если это именно числовой лимит, обычно правильно написать `max_search_results = 5`.

### Ошибка 3. Неправильный регистр логических значений

Неправильно: `true`, `false`. Правильно: `True`, `False`.

### Ошибка 4. Присваивание путают с проверкой равенства

`=` задаёт значение, `==` сравнивает значения. Сравнения подробно разберём в уроке про условия.

### Ошибка 5. Непонятное имя переменной

Имя `x` не сообщает, что хранится. Для настройки используйте, например, `timeout_seconds`.

### Ошибка 6. Ожидание, что комментарий выполнится

`# print("Привет")` — комментарий, поэтому команда не запустится. Удалите `#`, если нужно выполнить вывод.

### Ошибка 7. Неправильный путь к файлу

Если команда запускается не из той папки, Python может не найти файл или модуль. Сначала проверьте текущий каталог командой `Get-Location`, затем перейдите в нужную папку с помощью `cd`.
