## 1. Почему одной переменной уже недостаточно

Представим, что инструмент \`web_search\` получил запрос «Python MCP». Поиск может вернуть пять страниц. У каждой страницы есть заголовок, URL и короткое описание.

Можно было бы создать отдельные переменные:

~~~python
title_1 = "Документация Python"
title_2 = "Документация MCP"
title_3 = "Пример сервера"
~~~

Но если поиск вернёт 20 или 100 результатов, придётся создавать десятки или сотни переменных. Код станет длинным, а обработать все значения одинаковым способом будет неудобно.

Нам нужна **структура данных** — способ организованно хранить несколько значений и обращаться к ним по определённым правилам.

В Python есть разные структуры данных. Сегодня разберём две основные:
- **список** (\`list\`) — упорядоченная последовательность элементов;
- **словарь** (\`dict\`) — набор пар «ключ — значение».

А ещё научимся повторять действия над элементами с помощью **цикла** (\`loop\`) и разберём формат обмена данными **JSON**.

## 2. Список: несколько элементов под одним именем

### 2.1. Создаём список

Список создаётся с помощью квадратных скобок \`[]\`. Элементы перечисляются через запятую.

~~~python
search_queries = ["Python", "MCP", "LM Studio"]

print(search_queries)
~~~

Результат:

~~~text
['Python', 'MCP', 'LM Studio']
~~~

Разберём код:
- \`search_queries\` — имя переменной. Оно описывает, что именно хранится внутри.
- \`=\` — оператор присваивания. Он связывает имя переменной с созданным объектом списка.
- \`[]\` — квадратные скобки, обозначающие список.
- \`"Python"\`, \`"MCP"\`, \`"LM Studio"\` — три строковых элемента.
- \` , \` между элементами — разделитель, а не отдельная команда.
- \`print()\` выводит представление списка на экран.

В отличие от отдельной строки, список позволяет хранить целую коллекцию значений под одним именем.

### 2.2. Список может содержать значения разных типов

~~~python
example_values = ["Python", 5, True, None]
print(example_values)
~~~

Здесь строка, целое число, логическое значение и специальное значение \`None\` помещены в один список. Python это допускает. Однако в прикладной программе лучше придерживаться понятной структуры: например, список результатов поиска обычно состоит из словарей одного формата.

### 2.3. Индексы: как обратиться к отдельному элементу

**Индекс** (\`index\`) — номер позиции элемента в последовательности. В Python нумерация начинается с нуля.

~~~python
search_queries = ["Python", "MCP", "LM Studio"]

print(search_queries[0])
print(search_queries[1])
print(search_queries[2])
~~~

Результат:

~~~text
Python
MCP
LM Studio
~~~

**Новая конструкция:** квадратные скобки после имени списка — \`search_queries[0]\` — используются здесь не для создания списка, а для получения элемента по индексу.

Почему индекс начинается с нуля? Это правило языка Python. Поэтому индекс последнего элемента списка из трёх значений равен \`2\`, а не \`3\`.

Если запросить элемент, которого нет, например \`search_queries[3]\`, программа вызовет ошибку \`IndexError\`. Это пример ошибки выхода за границы списка.

### 2.4. Отрицательные индексы

В Python отрицательные индексы позволяют обращаться к элементам с конца:

~~~python
search_queries = ["Python", "MCP", "LM Studio"]

print(search_queries[-1])
print(search_queries[-2])
~~~

Результат:

~~~text
LM Studio
MCP
~~~

- \`[-1]\` — последний элемент;
- \`[-2]\` — предпоследний элемент.

Это удобно, когда нужен последний результат, а точное количество элементов заранее неизвестно. Но список должен быть непустым, иначе обращение к \`[-1]\` тоже вызовет \`IndexError\`.

### 2.5. Узнаём количество элементов: \`len()\`

Функция \`len()\` возвращает количество элементов в списке.

~~~python
search_queries = ["Python", "MCP", "LM Studio"]

print(len(search_queries))
~~~

Результат:

~~~text
3
~~~

**Функция** — именованный блок кода, который выполняет задачу и может вернуть результат. Функцию \`len()\` мы не создаём самостоятельно: она встроена в Python.

Зачем нужна \`len()\`:
- проверить, пустой ли список;
- узнать количество результатов;
- ограничить обработку данных;
- вывести пользователю, сколько страниц найдено.

Например:

~~~python
if len(search_queries) == 0:
    print("Список запросов пуст")
else:
    print(f"Количество запросов: {len(search_queries)}")
~~~

Здесь используется знакомая конструкция \`if/else\` из урока № 4. Выражение \`len(search_queries) == 0\` проверяет, равняется ли количество элементов нулю.

Для списков часто используют более короткую проверку:

~~~python
if not search_queries:
    print("Список запросов пуст")
~~~

Пустой список в условии считается ложным значением, а непустой — истинным. Выражение \`not search_queries\` означает «список пуст или иначе оценивается как ложный». Для списка это удобная и распространённая проверка.

### 2.6. Добавляем элементы: метод \`.append()\`

**Метод** (\`method\`) — операция, связанная с объектом и вызываемая через точку после его имени. Например, \`search_queries.append(...)\`.

~~~python
search_queries = ["Python", "MCP"]
search_queries.append("LM Studio")

print(search_queries)
~~~

Результат:

~~~text
['Python', 'MCP', 'LM Studio']
~~~

Метод \`.append()\` добавляет один элемент в конец существующего списка.

Важно: метод изменяет исходный список. Не нужно писать \`search_queries = search_queries.append("LM Studio")\`: \`.append()\` изменяет список на месте и возвращает \`None\`, а не новый список. Если присвоить результат переменной, можно случайно потерять ссылку на список.

Пример добавления результата в будущей поисковой программе:

~~~python
results = []
results.append("Первая найденная страница")
results.append("Вторая найденная страница")
print(results)
~~~

Сначала \`results = []\` создаёт пустой список. Затем каждый вызов \`.append()\` добавляет в него новый элемент.

## 3. Словарь: данные, связанные с именованными полями

Списка достаточно, чтобы хранить набор элементов, но результат поиска состоит из нескольких связанных свойств: заголовка, адреса и описания. Если хранить их в отдельных списках, легко перепутать, какой заголовок относится к какому адресу.

Для этого подходит **словарь** (\`dict\`, от *dictionary* — «словарь»). Он хранит пары «ключ — значение».

### 3.1. Создаём словарь

~~~python
page = {
    "title": "Документация Python",
    "url": "https://docs.python.org/",
    "description": "Официальная документация языка Python."
}

print(page)
~~~

Словарь заключён в фигурные скобки \`{}\`. Каждая запись имеет форму \`ключ: значение\`. Записи разделяются запятыми.

В нашем примере:
- \`"title"\` — ключ для заголовка;
- \`"url"\` — ключ для адреса страницы;
- \`"description"\` — ключ для описания;
- значения справа от двоеточия содержат сами данные.

Ключи здесь — строки. Значения тоже строки, но словари в целом могут хранить числа, логические значения, списки, другие словари и другие поддерживаемые типы.

### 3.2. Получаем значение по ключу

~~~python
print(page["title"])
print(page["url"])
~~~

Результат:

~~~text
Документация Python
https://docs.python.org/
~~~

**Новая конструкция:** \`page["title"]\` обращается к значению по ключу, а не по числовому индексу. В списке мы обычно спрашиваем «какой элемент на позиции 0?», а в словаре — «какое значение связано с ключом title?».

Если ключа нет, обращение \`page["snippet"]\` вызовет \`KeyError\`. Это не то же самое, что \`IndexError\`: первая ошибка связана с отсутствующим ключом словаря, вторая — с несуществующей позицией в последовательности.

### 3.3. Безопасное получение значения: \`.get()\`

Результаты разных поисковых сервисов могут отличаться. Одна страница содержит описание, другая — нет. Поэтому полезно научиться получать поле безопасно.

~~~python
description = page.get("description")
snippet = page.get("snippet")

print(description)
print(snippet)
~~~

Если ключ отсутствует, \`.get()\` по умолчанию возвращает \`None\`, а не вызывает \`KeyError\`.

Можно задать запасное значение:

~~~python
snippet = page.get("snippet", "Описание не предоставлено")
print(snippet)
~~~

Второй аргумент \`.get()\` — значение по умолчанию. Оно используется, если ключ отсутствует. Это удобно при обработке необязательных полей.

Но помните: \`.get()\` возвращает значение по умолчанию только при отсутствии ключа. Если ключ существует и содержит пустую строку, вернётся пустая строка.

### 3.4. Изменяем и добавляем поля

~~~python
page["title"] = "Обновлённый заголовок"
page["language"] = "ru"

print(page["title"])
print(page["language"])
~~~

Присваивание значения по существующему ключу изменяет поле. Присваивание по новому ключу добавляет новую пару «ключ — значение».

В Python словари изменяемые: их содержимое можно менять после создания. Это удобно при нормализации результатов поиска, например когда мы дополняем каждую страницу полем языка или источника.

### 3.5. Проверяем наличие ключа с помощью \`in\`

~~~python
if "url" in page:
    print("У страницы есть URL")
~~~

Оператор \`in\` проверяет принадлежность. Для словаря проверка \`"url" in page\` означает: «есть ли ключ \`"url"\` в словаре?». Она не проверяет, содержится ли текст \`"url"\` внутри какого-либо значения.

Для списка \`in\` проверяет, присутствует ли элемент среди элементов:

~~~python
if "MCP" in ["Python", "MCP", "LM Studio"]:
    print("Запрос найден в списке")
~~~

Это один оператор, но его смысл зависит от типа данных. В словаре \`in\` по умолчанию проверяет ключи.

## 4. Самая важная структура нашего проекта: список словарей

Результат веб-поиска — это обычно несколько записей. Каждая запись описывает отдельную страницу. Значит, можно создать словарь для одной страницы, а затем поместить несколько таких словарей в список.

~~~python
results = [
    {
        "title": "Документация Python",
        "url": "https://docs.python.org/",
        "description": "Официальная документация Python."
    },
    {
        "title": "Model Context Protocol",
        "url": "https://modelcontextprotocol.io/",
        "description": "Документация протокола MCP."
    },
    {
        "title": "LM Studio",
        "url": "https://lmstudio.ai/",
        "description": "Программа для запуска языковых моделей."
    }
]
~~~

Разберём структуру:
1. Внешние квадратные скобки \`[]\` создают список результатов.
2. Каждый элемент списка — словарь в фигурных скобках \`{}\`.
3. Внутри словаря ключи \`title\`, \`url\`, \`description\` обозначают поля страницы.
4. Запятые отделяют элементы списка и записи словарей.

Схематично структура выглядит так:

~~~text
results (список)
  ├── элемент 0 (словарь страницы)
  │     ├── title
  │     ├── url
  │     └── description
  ├── элемент 1 (словарь страницы)
  │     ├── title
  │     ├── url
  │     └── description
  └── элемент 2 (словарь страницы)
        ├── title
        ├── url
        └── description
~~~

Теперь можно обратиться к первому результату и его заголовку:

~~~python
print(results[0]["title"])
~~~

Сначала \`results[0]\` выбирает первый словарь из списка, а затем \`["title"]\` получает заголовок из этого словаря.

Такая модель данных будет встречаться в нашем проекте постоянно: список результатов поиска, где каждый результат — словарь с определёнными полями.

## 5. Цикл \`for\`: повторяем действие для каждого элемента

Если нужно вывести все три заголовка, можно написать три отдельных команды. Но если результатов 50, такой подход не годится. Нам нужна конструкция, которая повторит действия для каждого элемента списка.

**Цикл** (\`loop\`) — конструкция языка программирования, позволяющая многократно выполнять блок кода. Цикл \`for\` в Python проходит по элементам последовательности или другого перебираемого объекта.

~~~python
for page in results:
    print(page["title"])
~~~

Результат:

~~~text
Документация Python
Model Context Protocol
LM Studio
~~~

Разберём каждую часть:
- \`for\` — ключевое слово, начинающее цикл.
- \`page\` — имя переменной цикла. На каждом шаге она получает очередной элемент списка. Имя можно выбрать другое, но лучше выбирать понятное.
- \`in\` — указывает, по какому набору элементов нужно пройти.
- \`results\` — список, элементы которого перебираем.
- \`:\` — двоеточие, после которого начинается блок цикла.
- строка \`print(page["title"])\` имеет отступ и выполняется для каждого элемента.

**Отступы важны.** В Python отступ показывает, какие команды принадлежат циклу или условию. Обычно используют четыре пробела. Команда без отступа после цикла выполняется уже после завершения цикла.

~~~python
for page in results:
    print(page["title"])

print("Обработка завершена")
~~~

Здесь сообщение «Обработка завершена» выводится один раз, после всех заголовков.

### 5.1. Почему \`for\` лучше ручного копирования

Цикл полезен потому что:
- работает с любым количеством элементов;
- уменьшает повторяющийся код;
- делает программу проще для изменения;
- позволяет одинаково проверять каждую страницу;
- помогает ограничивать и нормализовать результаты.

Если сервис вернёт 2 результата или 200, сам цикл менять не нужно.

### 5.2. Цикл и условие вместе

Часто для каждого результата нужно проверить определённое поле:

~~~python
for page in results:
    if page.get("url"):
        print(page["url"])
~~~

Для каждой страницы цикл получает словарь. Затем условие проверяет, возвращает ли поле \`url\` непустое значение. Если поле отсутствует, \`.get("url")\` вернёт \`None\`, и тело условия не выполнится.

Так мы сочетаем новую конструкцию \`for\` с уже изученными \`if\` и функцией \`.get()\`.

## 6. \`range()\` и функция \`enumerate()\`

### 6.1. Когда нужен счётчик: \`range()\`

Функция \`range()\` создаёт последовательность целых чисел, которую часто используют в циклах.

~~~python
for number in range(3):
    print(number)
~~~

Результат:

~~~text
0
1
2
~~~

\`range(3)\` даёт числа от нуля до значения перед верхней границей — то есть 0, 1 и 2. Число 3 в последовательность не входит.

Можно задать начало и конец:

~~~python
for number in range(1, 4):
    print(number)
~~~

Результат:

~~~text
1
2
3
~~~

Форма \`range(start, stop)\` включает \`start\`, но не включает \`stop\`. Это правило помогает вычислять количество шагов: \`range(1, 4)\` содержит три значения.

Однако для перебора самих страниц обычно лучше писать \`for page in results\`, а не создавать индексы вручную. Прямой перебор проще читать и снижает вероятность ошибки с индексом.

### 6.2. Номер результата и сам результат: \`enumerate()\`

В отчёте поиска удобно выводить результаты с номерами: 1, 2, 3. Функция \`enumerate()\` позволяет получать одновременно номер и элемент.

~~~python
for number, page in enumerate(results, start=1):
    print(f"{number}. {page['title']}")
~~~

Результат:

~~~text
1. Документация Python
2. Model Context Protocol
3. LM Studio
~~~

Что здесь нового:
- \`enumerate(results, start=1)\` перебирает список и выдаёт пары «номер — элемент».
- \`start=1\` задаёт начало нумерации с единицы, что удобно для человека.
- \`number, page\` — две переменные, которым на каждом шаге присваиваются номер и очередной словарь.
- \`f"..."\` — знакомая f-строка, которая подставляет значения переменных в текст.
- \`{page['title']}\` — внутри выражения f-строки используется ключ словаря. Внешние кавычки f-строки двойные, а ключ записан в одинарных кавычках, чтобы строки не конфликтовали.

Преимущество \`enumerate()\`: не нужно вручную увеличивать счётчик и отдельно обращаться к списку по индексу.

## 7. Ограничиваем количество результатов

В настройках будущего сервера у нас будет ограничение на число результатов. Например, хотим показать максимум пять страниц. На этом уроке разберём простой вариант среза списка.

**Срез** (\`slice\`) — способ получить часть последовательности. Запись \`results[:5]\` означает «взять элементы от начала до индекса 5, не включая его».

~~~python
top_results = results[:2]

for page in top_results:
    print(page["title"])
~~~

Здесь \`results[:2]\` создаёт новый список из первых двух элементов исходного списка. Исходный список при этом не удаляется и не обрезается.

Можно использовать переменную настройки:

~~~python
max_results = 2
top_results = results[:max_results]
print(f"Показываем результатов: {len(top_results)}")
~~~

Это полезно, потому что лимит можно изменить в одном месте. В реальном сервере дополнительно нужно проверять, что настройка имеет допустимый тип и значение. Здесь мы изучаем сам принцип ограничения.

## 8. JSON: формат обмена данными

**JSON** расшифровывается как *JavaScript Object Notation* — «объектная нотация JavaScript». Несмотря на название, JSON широко используется разными языками программирования. Это текстовый формат для хранения и передачи структурированных данных.

Почему JSON важен для нашего проекта:
- программы могут обмениваться данными независимо от языка реализации;
- структура данных остаётся читаемой человеком;
- результаты поиска можно представить в виде массива объектов;
- многие API и инструменты используют JSON;
- позже MCP будет передавать структурированные аргументы и результаты между клиентом и сервером.

Пример JSON-документа:

~~~json
{
  "query": "Python MCP",
  "results": [
    {
      "title": "Документация Python",
      "url": "https://docs.python.org/",
      "description": "Официальная документация Python."
    },
    {
      "title": "Документация MCP",
      "url": "https://modelcontextprotocol.io/",
      "description": "Документация протокола MCP."
    }
  ]
}
~~~

В этом примере:
- фигурные скобки обозначают JSON-объект;
- \`"query"\` — поле со строковым значением;
- \`"results"\` — поле, содержащее массив;
- квадратные скобки обозначают массив элементов;
- каждый элемент массива — объект с полями страницы.

### 8.1. Python и JSON — не одно и то же

Python-словарь и JSON-объект внешне похожи, но это разные вещи:
- Python-словарь — объект внутри программы Python;
- JSON — текстовое представление данных для обмена.

Например, в Python можно хранить значение \`None\`, а в JSON аналогом будет \`null\`. В Python логические значения пишутся \`True\` и \`False\`, а в JSON — \`true\` и \`false\`. JSON требует двойные кавычки вокруг строк и имён полей.

### 8.2. Модуль \`json\`

**Модуль** (\`module\`) — файл или компонент с готовыми функциями и объектами, которые можно подключить и использовать. Модуль \`json\` входит в стандартную библиотеку Python, поэтому отдельно устанавливать его не нужно.

~~~python
import json

data = {
    "query": "Python MCP",
    "count": 2,
    "success": True,
    "results": [
        {"title": "Документация Python", "url": "https://docs.python.org/"},
        {"title": "Документация MCP", "url": "https://modelcontextprotocol.io/"}
    ]
}

json_text = json.dumps(data, ensure_ascii=False, indent=2)
print(json_text)
~~~

Новые конструкции:
- \`import json\` подключает стандартный модуль \`json\`.
- \`json.dumps(...)\` преобразует Python-объект в строку JSON. Название можно запомнить как «dump string»: сериализация в текст.
- \`ensure_ascii=False\` позволяет оставлять русские буквы в читаемом виде, а не заменять их последовательностями вида \`\\u0414\`.
- \`indent=2\` форматирует JSON с отступами в два пробела, чтобы его было удобно читать.
- \`json_text\` содержит именно строку, а не словарь.

**Сериализация** — преобразование объекта в формат, который можно сохранить или передать. В этом примере Python-словарь сериализуется в JSON-текст.

Параметры \`ensure_ascii=False\` и \`indent=2\` не обязательны для корректности JSON, но повышают читаемость результата при отладке.

### 8.3. Обратное преобразование: \`json.loads()\`

Если у нас есть строка JSON, можно преобразовать её обратно в Python-структуры:

~~~python
import json

json_text = '{"query": "Python MCP", "count": 2, "success": true}'

data = json.loads(json_text)

print(data["query"])
print(data["count"])
print(data["success"])
~~~

Результат:

~~~text
Python MCP
2
True
~~~

\`json.loads()\` читает JSON-строку и создаёт соответствующие Python-объекты. Название связано с загрузкой строки (*load string*).

**Десериализация** — обратный процесс: преобразование текстового представления в структуры данных программы.

Важно различать:
- \`json.dumps(data)\` — Python-объект → JSON-строка;
- \`json.loads(json_text)\` — JSON-строка → Python-объект.

Есть также \`json.dump()\` и \`json.load()\`, которые работают с файловыми объектами. Их подробно рассмотрим, когда дойдём до чтения и записи файлов.

### 8.4. Какие типы поддерживает JSON

Основные соответствия:

| Python | JSON |
|---|---|
| \`dict\` | объект |
| \`list\` | массив |
| \`str\` | строка |
| \`int\`, \`float\` | число |
| \`True\` | \`true\` |
| \`False\` | \`false\` |
| \`None\` | \`null\` |

Не любой объект Python можно напрямую сериализовать в JSON. Например, пользовательский объект или некоторые специальные типы могут вызвать \`TypeError\`. Для нашего проекта важно возвращать понятные структуры из словарей, списков, строк, чисел, логических значений и \`None\`.

## 9. Пустые данные и отсутствующие поля

Реальные данные часто неполные. Поиск может вернуть пустой список, а у отдельной страницы может отсутствовать описание. Хорошая программа должна спокойно обрабатывать такие случаи.

### 9.1. Пустой список

~~~python
results = []

if not results:
    print("По запросу ничего не найдено")
~~~

Пустой список допустим и сам по себе не является ошибкой. Ошибкой будет предположение, что в нём всегда есть хотя бы один элемент.

Например, \`results[0]\` при пустом списке вызовет \`IndexError\`. Поэтому сначала проверяем список или перебираем его циклом: цикл по пустому списку просто не выполнит тело ни разу.

### 9.2. Отсутствующее описание

~~~python
page = {
    "title": "Документация Python",
    "url": "https://docs.python.org/"
}

description = page.get("description", "Описание отсутствует")
print(description)
~~~

Метод \`.get()\` не позволяет отсутствующему ключу немедленно остановить программу. При этом не стоит подставлять выдуманное описание: запасной текст явно сообщает, что описание не предоставлено.

### 9.3. Пустая строка и отсутствующий ключ — разные случаи

~~~python
page = {
    "title": "Документация Python",
    "description": ""
}

print(page.get("description", "Нет поля"))
print(page.get("snippet", "Нет поля"))
~~~

Результат:

~~~text

Нет поля
~~~

Первый вызов возвращает пустую строку, потому что ключ существует. Второй возвращает текст по умолчанию, потому что ключа \`snippet\` нет.

Это различие полезно при обработке внешних данных: поле может существовать, но быть пустым.

## 10. Практический мини-проект: подготовка результатов поиска

Соберём всё изученное в одной программе. Она:
1. хранит несколько условных результатов поиска;
2. ограничивает количество отображаемых страниц;
3. перебирает их с помощью \`for\` и \`enumerate()\`;
4. безопасно получает необязательное описание;
5. создаёт структуру для передачи дальше;
6. преобразует эту структуру в JSON и выводит его.

Создайте файл \`lesson_05.py\` в папке курса и вставьте код:

~~~python
import json

query = "Python MCP"
max_results = 2

results = [
    {
        "title": "Документация Python",
        "url": "https://docs.python.org/",
        "description": "Официальная документация языка Python."
    },
    {
        "title": "Model Context Protocol",
        "url": "https://modelcontextprotocol.io/",
        "description": "Документация протокола MCP."
    },
    {
        "title": "LM Studio",
        "url": "https://lmstudio.ai/"
    }
]

selected_results = results[:max_results]

if not selected_results:
    print("По запросу ничего не найдено")
else:
    print(f"Запрос: {query}")
    print(f"Количество результатов: {len(selected_results)}")

    for number, page in enumerate(selected_results, start=1):
        title = page.get("title", "Без заголовка")
        url = page.get("url", "")
        description = page.get("description", "Описание отсутствует")

        print(f"{number}. {title}")
        print(f"   URL: {url}")
        print(f"   Описание: {description}")

output = {
    "query": query,
    "count": len(selected_results),
    "results": selected_results
}

json_text = json.dumps(output, ensure_ascii=False, indent=2)

print()
print("JSON для передачи другой программе:")
print(json_text)
~~~

### 10.1. Объяснение программы по частям

**Часть 1. Подключение модуля и настройки**

~~~python
import json

query = "Python MCP"
max_results = 2
~~~

Мы подключаем стандартный модуль \`json\`, сохраняем поисковый запрос и максимальное число результатов в переменных. Число 2 выбрано для демонстрации; позже это значение станет настройкой инструмента.

**Часть 2. Данные поиска**

~~~python
results = [
    {"title": "Документация Python", "url": "https://docs.python.org/", "description": "Официальная документация языка Python."},
    {"title": "Model Context Protocol", "url": "https://modelcontextprotocol.io/", "description": "Документация протокола MCP."},
    {"title": "LM Studio", "url": "https://lmstudio.ai/"}
]
~~~

Это список из трёх словарей. У третьей страницы отсутствует описание. Такой пример намеренно показывает, что программа не должна предполагать полное совпадение полей у всех записей.

**Часть 3. Ограничение количества результатов**

~~~python
selected_results = results[:max_results]
~~~

Срез создаёт список, содержащий первые два результата. Исходный список \`results\` остаётся без изменений. Если позже изменить \`max_results\`, ограничение изменится автоматически.

**Часть 4. Проверка пустого списка**

~~~python
if not selected_results:
    print("По запросу ничего не найдено")
else:
    ...
~~~

Если список пуст, выводим сообщение. Если он не пуст, выполняем блок \`else\`. Три точки в этом объяснительном фрагменте означают пропущенный код; в настоящем файле вместо них находятся команды вывода и цикл.

**Часть 5. Цикл и извлечение полей**

~~~python
for number, page in enumerate(selected_results, start=1):
    title = page.get("title", "Без заголовка")
    url = page.get("url", "")
    description = page.get("description", "Описание отсутствует")
~~~

На каждом шаге \`number\` получает порядковый номер, а \`page\` — очередной словарь. Метод \`.get()\` помогает обработать отсутствующие поля. Для URL запасное значение — пустая строка; для заголовка и описания — понятный текст.

**Часть 6. Формирование выходного объекта**

~~~python
output = {
    "query": query,
    "count": len(selected_results),
    "results": selected_results
}
~~~

Создаём словарь с запросом, числом результатов и самим списком. Это структурированное представление, которое можно преобразовать в JSON.

**Часть 7. Сериализация**

~~~python
json_text = json.dumps(output, ensure_ascii=False, indent=2)
~~~

Получаем текст JSON. Этот текст можно показать, записать в файл или передать другой программе. В будущей реализации MCP не нужно будет вручную печатать JSON в стандартный вывод для передачи результата: MCP-библиотека сама управляет протоколом. Здесь вывод JSON нужен только для обучения и проверки.

## 11. Новые конструкции урока: краткая памятка

| Конструкция | Что делает | Зачем нужна в проекте |
|---|---|---|
| \`[]\` | Создаёт список или выбирает элемент по индексу/срезу | Хранить набор результатов |
| \`{}\` | Создаёт словарь | Хранить поля одной страницы |
| \`list.append(value)\` | Добавляет элемент в конец списка | Собирать результаты по мере получения |
| \`dict.get(key, default)\` | Получает поле безопасно | Обрабатывать необязательные поля |
| \`key in dict\` | Проверяет наличие ключа | Проверять структуру записи |
| \`len(value)\` | Возвращает количество элементов | Проверять пустоту и считать результаты |
| \`for item in collection\` | Перебирает элементы | Обрабатывать все страницы |
| \`range(stop)\` | Создаёт последовательность чисел | Повторять действия заданное число раз |
| \`enumerate(items, start=1)\` | Даёт номер и элемент | Нумеровать результаты |
| \`items[:limit]\` | Получает часть списка | Ограничивать количество результатов |
| \`import json\` | Подключает модуль JSON | Обмениваться структурированными данными |
| \`json.dumps()\` | Превращает Python-данные в JSON-текст | Подготовить текстовый формат |
| \`json.loads()\` | Превращает JSON-текст в Python-данные | Прочитать полученные JSON-данные |

Обратите внимание на разницу между **оператором**, **функцией** и **методом**:
- оператор — элемент языка, выполняющий действие или задающий отношение, например \`in\`, \`=\`, \`==\`;
- функция — вызываемая операция, например \`len()\`, \`range()\`, \`enumerate()\`;
- метод — операция, вызываемая у конкретного объекта через точку, например \`.append()\` или \`.get()\`.

В разговорной речи их иногда называют одним словом «команда», но в программировании различать их полезно.

## 12. Частые ошибки новичков

### Ошибка 1. Индекс вне диапазона

~~~python
items = ["Python", "MCP"]
print(items[2])
~~~

В списке два элемента, допустимые индексы — 0 и 1. Обращение к индексу 2 вызовет \`IndexError\`. Проверяйте размер списка и помните, что нумерация начинается с нуля.

### Ошибка 2. Несуществующий ключ

~~~python
page = {"title": "Документация Python"}
print(page["url"])
~~~

Ключа \`url\` нет, поэтому возникнет \`KeyError\`. Если поле необязательно, используйте \`page.get("url", "")\` или предварительную проверку \`if "url" in page\`.

### Ошибка 3. Забытый отступ после \`for\`

~~~python
for item in items:
print(item)
~~~

Python ожидает отступ у тела цикла и выдаст \`IndentationError\`. Правильный вариант:

~~~python
for item in items:
    print(item)
~~~

### Ошибка 4. Путаем JSON-текст и Python-словарь

~~~python
data = '{"title": "Документация Python"}'
print(data["title"])
~~~

Переменная \`data\` содержит строку, а не словарь. Обращение по ключу здесь не сработает. Сначала выполните \`data = json.loads(data)\`, затем обращайтесь к \`data["title"]\`.

### Ошибка 5. Пишем JSON как Python

В JSON логическое значение записывается как \`true\`, а в Python — как \`True\`. Если вручную составлять JSON-текст, следите за синтаксисом. Лучше использовать \`json.dumps()\`, чтобы сериализатор сформировал корректный JSON.

### Ошибка 6. Присваиваем результат \`.append()\`

~~~python
items = ["Python"]
items = items.append("MCP")
print(items)
~~~

После вызова \`.append()\` переменная станет равна \`None\`, потому что метод изменяет список на месте и не возвращает новый список. Правильно:

~~~python
items = ["Python"]
items.append("MCP")
print(items)
~~~

### Ошибка 7. Предполагаем, что описание есть у каждой страницы

~~~python
description = page["description"]
~~~

Если поля нет, программа завершится с \`KeyError\`. Для необязательного поля лучше:

~~~python
description = page.get("description", "Описание отсутствует")
~~~

### Задание 1. Создайте список

Создайте список из четырёх поисковых запросов на темы Python, MCP и LM Studio. Выведите весь список, первый элемент, последний элемент и количество элементов.

**Проверьте себя:** последний элемент можно получить через индекс \`-1\`, а количество — через \`len()\`.

### Задание 2. Измените список

Создайте список из двух строк, добавьте третью через \`.append()\`, затем выведите список. Не присваивайте результат вызова \`.append()\) обратно переменной.

### Задание 3. Создайте словарь страницы

Создайте словарь с полями \`title\`, \`url\` и \`description\`. Выведите заголовок и адрес. Затем добавьте поле \`source\` со значением \`"demo"\`.

### Задание 4. Обработайте необязательное поле

Создайте словарь, в котором есть \`title\`, но отсутствует \`description\`. С помощью \`.get()\` выведите значение по умолчанию \`"Описание отсутствует"\`.

### Задание 5. Переберите список словарей

Создайте список из трёх словарей страниц. Используя \`for\`, выведите заголовок каждой страницы. Затем переделайте цикл так, чтобы выводить номер и заголовок с помощью \`enumerate()\`.

### Задание 6. Ограничьте результаты

Создайте список из пяти словарей. Используйте переменную \`max_results = 3\` и срез, чтобы получить только первые три записи. Выведите количество отобранных результатов.

### Задание 7. Преобразуйте в JSON

Создайте словарь с поисковым запросом и списком из двух результатов. Подключите \`json\`, вызовите \`json.dumps(..., ensure_ascii=False, indent=2)\` и выведите строку. Убедитесь, что русские буквы отображаются нормально.

### Задание 8. Прочитайте JSON

Создайте строку с корректным JSON, содержащим поля \`title\` и \`url\). Преобразуйте строку с помощью \`json.loads()\` и выведите значение \`title\`.

### Дополнительное задание

Напишите функцию \`prepare_results(results, max_results)\`, которая:
1. принимает список словарей и максимальное число результатов;
2. отбирает первые \`max_results\` элементов;
3. возвращает новый словарь с полями \`count\` и \`results\`;
4. не выводит информацию через \`print()\` внутри функции, а возвращает данные через \`return\`.

Это задание соединяет материал урока № 4 (функции и \`return\`) с темами текущего урока (списки, словари и срезы).

## 15. Итоги урока

В этом уроке мы перешли от отдельных значений к структурам данных. Список хранит последовательность элементов, словарь связывает ключи с данными, цикл позволяет обрабатывать элементы без копирования кода, а JSON даёт текстовый формат для обмена структурированными данными.

В будущей реализации \`web_search\` поисковый сервис вернёт несколько страниц. Мы будем представлять их как список словарей, проверять и ограничивать количество результатов, безопасно обрабатывать отсутствующие поля и передавать данные дальше в согласованном формате.

Главное, что нужно запомнить:
- список — это набор элементов;
- словарь — это поля с именованными ключами;
- \`for\` обрабатывает каждый элемент;
- \`.get()\` помогает безопасно читать необязательные поля;
- \`len()\` считает элементы;
- срез \`[:limit]\` ограничивает набор;
- \`json.dumps()\` создаёт JSON-строку, а \`json.loads()\` читает JSON-строку.

**В следующем уроке № 6** мы разберём модули, сторонние библиотеки, виртуальное окружение и установку зависимостей. Это подготовит проект к реальным HTTP-запросам и работе с библиотекой MCP.
