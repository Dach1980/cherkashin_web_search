# Исправление DNS rebinding в web_fetch

Дата: 2026-11-18  
Репозиторий: `Dach1980/cherkashin_web_search`  
Ветка: `main`

## Исходная проблема

Ранее `web_fetch` проверял DNS через `socket.getaddrinfo()`, а затем передавал исходный hostname в HTTPX. HTTPX выполнял собственное DNS-разрешение при установлении TCP-соединения. Между проверкой и соединением DNS-ответ мог измениться (TOCTOU / DNS rebinding).

## Принятое техническое решение

Реализация в `src/web_search_mcp/web_fetch.py` теперь:

1. Разбирает URL и проверяет схему, учётные данные и локальные имена.
2. Для доменного имени получает полный набор адресов через системный resolver.
3. Отклоняет запрос, если DNS не вернул адреса либо хотя бы один полученный адрес не является глобальным.
4. Выбирает проверенный публичный IP.
5. Строит URL HTTP-запроса с этим IP-литералом, а не с исходным hostname. Поэтому HTTPX соединяется с указанным IP, не выполняя DNS lookup исходного имени.
6. Для HTTPS передаёт исходное имя в TLS SNI/проверку сертификата и сохраняет исходное имя в HTTP Host.
7. Отключает автоматические редиректы. Каждый Location обрабатывается вручную; новый URL проходит ту же процедуру проверки и закрепления IP до следующего соединения.
8. Не отключает TLS certificate verification.

Для этого используется документированное расширение HTTPX `sni_hostname` при запросе к IP-адресу с исходным Host: https://www.python-httpx.org/advanced/extensions/

## Добавленные тесты

В `tests/test_web_fetch.py` добавлены проверки:
- соединение адресуется к IP из проверенного DNS-ответа;
- исходный Host и TLS SNI сохраняются, включая нестандартный порт;
- исходный hostname разрешается один раз до отправки запроса;
- смешанный DNS-ответ (публичный + loopback) отклоняется;
- перенаправление на loopback не приводит ко второму сетевому запросу;\n- публичный IPv6-адрес закрепляется в URL запроса;\n- при перенаправлении на другое публичное доменное имя выполняется новое разрешение и закрепляется новый IP.

Существующие тесты загрузчика адаптированы к использованию `httpx.Client` и `Client.send(..., stream=True)`.
