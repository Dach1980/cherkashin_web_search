# Python с нуля до MCP Web Search для LM Studio

Практический курс по созданию собственного MCP-сервера на Python с инструментами `web_search` и `web_fetch`.

## Цель курса

Постепенно создать MCP-сервер, который позволяет языковой модели искать информацию в интернете, загружать страницы и отвечать на основе полученного содержимого.

Итоговый сервер должен запускаться средствами LM Studio без открытого Visual Studio Code и без ручного запуска команды разработки в терминале. В базовом варианте может требоваться установленный Python; упаковка в самостоятельный `.exe` — дополнительная тема.

## Программа курса

### Основной курс — 17 уроков

1. От Python до MCP: архитектура проекта.
2. Установка Python и Visual Studio Code.
3. Переменные, типы данных, строки и комментарии.
4. Условия, функции и возврат результата.
5. Списки, словари, циклы и JSON.
6. Модули, библиотеки и виртуальное окружение.
7. Интернет-запросы и обработка ошибок.
8. Создаём Web Search.
9. Создаём Web Fetch.
10. Превращаем функции в MCP-сервер.
11. Безопасность, тестирование и исправление ошибок.
12. Подключаем MCP к LM Studio и запускаем без VS Code.
13. Конфигурация, переменные окружения и логирование.
14. Типизация Python и контракты функций.
15. Углублённое тестирование MCP-сервера.
16. Как модель использует Web Search и Web Fetch.
17. Надёжность поиска и извлечения текста.

### Дополнительные уроки

18. Асинхронность и параллельные запросы.
19. Упаковка в EXE и переносимая установка.

Уроки 18–19 не входят в обязательную программу и изучаются по желанию после основного курса.

## Принципы подготовки уроков

Каждый урок включает подробную лекцию, пригодную для записи видео; определения иностранных терминов; построчный разбор кода; отдельное объяснение новых операторов и конструкций с указанием причин выбора и преимуществ; инструкции для Windows, VS Code и PowerShell; команды запуска, ожидаемый результат, типичные ошибки, практическое задание, контрольные вопросы и критерии готовности.

Полный лекционный текст публикуется в чате и сохраняется в соответствующем каталоге репозитория — ссылки на файлы не заменяют текст урока в чате.

Сначала `web_search` и `web_fetch` проверяются как обычные Python-функции, затем объединяются в MCP-сервер. Автоматические тесты с подменённой сетью не считаются доказательством работоспособности реальных внешних сайтов или подключения к LM Studio.
